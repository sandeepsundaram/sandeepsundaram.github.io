AI-Powered API Schema Builder · Data Equity
2023
Generative-AI schema designer trained on 16,000+ API definitions, paired with a RAG enterprise contract generator.
60% automation lift

Problem

Enterprise API teams spend weeks turning ideas into well-formed, consistent API contracts, and even longer drafting the legal contracts that govern their use. We wanted to compress both into minutes without losing the rigour.

Approach

  • Fine-tuned a generative model on a corpus of 16,000+ OpenAPI definitions to suggest endpoints, schemas, and naming conventions matching house style.
  • Built a RAG pipeline over enterprise contract templates so the generator could draft clause-level language grounded in real precedent.
  • Wrapped both in a React workspace with reviewer-friendly diffs and one-click export to OpenAPI / Word.

Impact

  • 60% lift in document automation efficiency for enterprise contract drafting.
  • Anchor capability for Data Equity's commercial launch — first ARR landed within the first year.

DE API Marketplace · Data Equity
2024
A unified marketplace for API discovery, integration, and monetisation — from DE API Studio authoring through to metered billing and analytics.
Swagger · Redoc · GraphQL

Problem

API providers want their endpoints discovered and integrated by the right developers fast; developers want a single place to evaluate, try, and pay for APIs without learning a new portal each time.

Approach

  • Designed a multi-tenant portal that ingests OpenAPI / GraphQL specs and renders Swagger and Redoc documentation side-by-side.
  • Modelled flexible commercials — subscription, pay-as-you-go, and freemium — with metered billing baked in.
  • Pre-built onboarding workflows for sign-up, key issuance, scoped permissions, and review-then-publish for provider-side governance.
  • Surfaced usage analytics for both providers and consumers to make commercial decisions data-driven.

Impact

  • Cut API time-to-market for providers — list, document, and meter in a single workflow.
  • Productised the platform that anchors Data Equity's marketplace strategy.

DE Peppol Access Point · Data Equity
2024–25
Certified Peppol gateway for cross-border eInvoicing — single REST API across 20+ jurisdictions, validated, signed, and audit-trailed.
99.95% uptime SLA

Problem

Operating Peppol infrastructure independently means dealing with AS4 transport, per-country XML rules, SML lookups, certification, archiving, and a sprawl of jurisdictional quirks. Most ERPs, banks, and platforms shouldn't have to do that themselves.

Approach

  • Built a certified Access Point speaking AS4 over TLS 1.3, with sub-second SML lookups for participant registration.
  • Exposed a single REST API that handles UBL and PINT documents across 20+ jurisdictions (AU, NZ, SG, MY, JP, EU, UK).
  • Layered BIS 3.0 plus country-specific validation, multi-tenant RBAC, ISO 27001 controls, and tamper-evident archiving.
  • Sandbox-to-production in days, with data-residency controls per tenant.

Impact

  • 99.95% uptime SLA in production.
  • Lets ERPs, banks, and accounting platforms ship cross-border compliance without standing up their own Peppol stack.
